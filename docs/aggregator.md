# Модуль `webtop::aggregator`

## Обзор

Модуль агрегации и обработки системных метрик. Собирает данные из модуля `webtop::reader`, вычисляет производные значения (проценты загрузки CPU, скорость сети в Mbps), формирует унифицированные снапшоты состояния системы для отображения.

## Структуры данных (`common_snapshot.hpp`)

### `CpuSnapshot`

| Поле | Описание |
|------|----------|
| `usage_percent` | Общая загрузка CPU (0-100%) |
| `user_percent` | Время в пользовательском режиме |
| `system_percent` | Время в режиме ядра |
| `idle_percent` | Время простоя |
| `iowait_percent` | Время ожидания ввода-вывода |
| `cores_percent` | Загрузка каждого ядра (вектор) |

### `MemorySnapshot`

| Поле | Описание |
|------|----------|
| `total`, `used`, `available` | Память в MB |
| `used_percent` | Процент использования |
| `swap_total`, `swap_used`, `swap_used_percent` | Swap в MB и процент |
| `buff_cache` | Память буферов и кэша в KB |

### `DiskSnapshot`

| Поле | Описание |
|------|----------|
| `device`, `mount_point` | Устройство и точка монтирования |
| `total_mb`, `used_mb`, `free_mb` | Размеры в MB |
| `used_percent` | Процент использования |

### `NetworkSnapshot`

| Поле | Описание |
|------|----------|
| `rx_mbps`, `tx_mbps` | Скорость приёма/передачи в Мбит/с |
| `rx_bytes_total`, `tx_bytes_total` | Общее количество байт |

### `LoadAvgSnapshot`

| Поле | Описание |
|------|----------|
| `load_1min`, `load_5min`, `load_15min` | Средняя нагрузка за 1/5/15 минут |

### `FullProcessInfo`

| Поле | Описание |
|------|----------|
| `pid`, `ppid`, `uid`, `user` | Идентификаторы процесса и пользователя |
| `name`, `state` | Имя процесса и состояние |
| `memory` | Память в MB |
| `cpu_percent` | Загрузка CPU (вычисляется) |
| `vmem` | Виртуальная память в MB |
| `threads` | Количество потоков |
| `uptime_seconds` | Время жизни процесса |
| `total_ticks` | Общее время CPU в тиках |

### `FullProcessSnapshot`

| Поле | Описание |
|------|----------|
| `timestamp` | Время снимка |
| `total_count`, `thread_count` | Общее количество процессов и потоков |
| `system_total` | Суммарные тики CPU системы |
| `running_total`, `sleeping_total`, `stopped_total`, `zombie_total` | Количество процессов по состояниям |
| `processes` | Вектор структур `FullProcessInfo` - состояние каждого процесса |
| `cpu`, `memory` | Снапшоты CPU и памяти |

### `SystemSnapshot`

| Поле | Описание |
|------|----------|
| `timestamp` | Время снимка |
| `cpu`, `memory`, `disks`, `network`, `loadavg` | Агрегированные метрики |
| `total_procs_count`, `total_threads_count` | Общее количество процессов и потоков |
| `uptime_formatted` | Время работы системы в формате `d дд:чч:мм` |

## Классы-анализаторы (Analizers)

### `CpuAnalizer`

Вычисляет загрузку CPU по данным из `/proc/stat`.

**Методы**:
- `Compute(current)` - принимает вектор `CpuData`, возвращает `CpuSnapshot` с процентами загрузки
- `Reset()` - сбрасывает состояние класса, устанавливая флаг `first_run_ = true`, чтобы следующий вызов `Compute()` не учитывал предыдущее состояние.

**Особенности**: требуется не менее двух последовательных вызовов `Compute()` для получения корректных процентов (разностный метод).

### `NetworkAnalizer`

Вычисляет скорость сети в Мбит/с.

**Методы**:
- `Compute(current)` - принимает вектор `NetworkInterfaceStats`, возвращает `NetworkSnapshot` со скоростью rx/tx
- `Reset()` - сбрасывает состояние

**Особенности**: использует разницу во времени между вызовами. Учитывает только интерфейс маршрута по умолчанию (default route).

### `ProcAnalizer`

Вычисляет загрузку CPU для каждого процесса.

**Методы**:
- `Compute(current)` - принимает `FullProcessSnapshot`, возвращает обновлённый снапшот с заполненными `cpu_percent`
- `Reset()` - сбрасывает состояние

**Формула**: `cpu_percent = 100 * (proc_ticks_diff / system_total_diff) * cpu_count` - процент загруженности CPU процессом с нормировкой на количество ядер (как у `top`, `atop`, ...)

## Классы-строители (Builders)

### `ProcBuilder`

Формирует `FullProcessSnapshot` из данных парсера процессов.

**Метод**: `Build()` - возвращает полный снапшот процессов.

### `MemoryBuilder`

Формирует `MemorySnapshot` из данных парсера памяти.

**Метод**: `Build()` - возвращает снапшот памяти.

### `DiskBuilder`

Формирует вектор `DiskSnapshot` из данных парсера дисков.

**Метод**: `Build()` - возвращает вектор снапшотов дисков.

### `LoadAvgBuilder`

Формирует `LoadAvgSnapshot` из `/proc/loadavg`.

**Метод**: `Build()` - возвращает снапшот нагрузки.

### `UptimeBuilder`

Формирует форматированную строку времени работы системы.

**Метод**: `Build()` - возвращает строку вида `"1d 02:30"`.

## Главный класс `MetricsAggregator`

Основной интерфейс для получения метрик системы.

**Методы**:

| Метод | Описание |
|-------|----------|
| `GetCurrentSnapshot()` | Возвращает `SystemSnapshot` - основные метрики системы |
| `GetFullProcessSnapshot()` | Возвращает `FullProcessSnapshot` - детальная информация по всем процессам |
| `Reset()` | Сбрасывает состояние анализаторов CPU и сети |

Каждый из get-методов получает информацию опосредованно через анализаторы и/или билдеры и составляет конечные снимки, полностью заполненные данными.
