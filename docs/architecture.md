## Архитектура проекта 

Проект `webtop` представлен в модульно-слоённой архитектуре: 

### Backend

- `nlohmann::json` - 3rdparty-библиотека для работы с данными в JSON формате 

- [`webtop::logger`](./logger.md) - модуль, ответственный за направление и форматирование логгов проекта

- [`webtop::util`](./util.md) - модуль, содержащий некоторые общие инструменты, используемые в других модулях

- [`webtop::reader`](./reader.md) - модуль-слой доступа к данным (ресурсам системы, к stat'ам процессов). Ответственнен за чтение и предобработку информации для слоя `webtop::agregator`

- [`webtop::aggregator`](./aggregator.md) - модуль-слой агрегации и анализа прочитанных данных. Подготавливает и анализирует информацию при запросе от `webtop::server` 

- [`webtop::server`](./server.md) - модуль-слой связи с фронтендом. Занимается установлением соединений и обработкой запросов от фронтендом.

### Frontend

- [`static/`](./frontend.md) - модуль-слой представления. Показывает пользователю информацию, запрошенную у сервера. Представлен в статичном WebUI виде.
