
# Модуль `webtop::logger`

## Обзор

Модуль предоставляет потокобезопасный синглтон-логгер с поддержкой цветного вывода в терминал (с помощью Escape-последовательностей) и временных меток с точностью до миллисекунд.

## Класс `Logger`

Потокобезопасный логгер с поддержкой уровней логирования и цветового оформления.

### Уровни логирования

- `kDebug` - отладочные сообщения (выводятся только при включённом режиме отладки)
- `kInfo` - информационные сообщения
- `kWarning` - предупреждения
- `kError` - ошибки
- `kSuccess` - сообщения об успешном выполнении (форматируются как INFO)

### Методы

#### Статические

- `static Logger& Instance()` - возвращает ссылку на единственный синглтон логгера.

#### Настройка

- `void SetDebugPrinting(bool debug_printing)` - включает/выключает вывод отладочных сообщений.
- `void SetColoredOutput(bool colored_output)` - включает/выключает цветной вывод в терминал.

#### Логирование

- `void Debug(const std::string& text)` - выводит отладочное сообщение если `debug_printing_ == true`. Формат: `[ DEBUG ]\t<время>\t<текст>`
- `void Info(const std::string& text)` - выводит информационное сообщение. Формат: `[ INFO  ]\t<время>\t<текст>`
- `void Warning(const std::string& text)` - выводит предупреждение. Формат: `[ WARN  ]\t<время>\t<текст>`
- `void Error(const std::string& text)` - выводит сообщение об ошибке. Формат: `[ ERROR ]\t<время>\t<текст>`
- `void Success(const std::string& text)` - выводит сообщение об успехе. Формат: `[ INFO  ]\t<время>\t<текст>` (зелёным цветом при включённом цветном выводе)
- `void EmptyLine()` - выводит пустую строку.

### Формат временной метки

Временная метка имеет формат `ЧЧ:ММ:СС.мсс`, где `мсс` - миллисекунды (0-999).
