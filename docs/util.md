# Модуль `webtop::util`

## Обзор

В текущий момент модуль предоставляет утилиты для автоматического управления
ресурсами с использованием идиомы RAII и вспомогательную функцию для
освобождения памяти.

## Компоненты

### Класс `ScopeGuard<Func>`

RAII-обёртка, которая вызывает переданную функцию-очистки при разрушении, если
только вызов не был отключён.

#### Параметры шаблона

- `Func` - тип вызываемого объекта, который будет выполнен при разрушении.

#### Конструкторы

- `explicit ScopeGuard(F&& deleter)` - создаёт guard с переданной
  функцией-очистки. Guard активен по умолчанию. Требует, чтобы `F` не был типом
  `ScopeGuard`, чтобы компилятор мог отличить вызов конструктора с параметром от
  вызова конструктора перемещения.

- `ScopeGuard(ScopeGuard&& other)` noexcept - конструктор перемещения.
  Перемещает состояние из другого guard, отключая перемещнный guard.

#### Запрещённые операции

- Копирование (конструктор копирования и оператор присваивания запрещены)
- Перемещающее присваивание запрещено

#### Методы

- `void Disable()` - отключает выполнение функции-очистки при разрушении. После
  вызова этого метода функция не будет вызвана.

#### Деструктор

Вызывает функцию-очистки, если guard активен.

### Функция `MakeScopeGuard`

```cpp
template <typename Func> auto MakeScopeGuard(Func &&f)
```

Создаёт объект `ScopeGuard` с выводом типа. Принимает вызываемый объект и
возвращает `ScopeGuard<std::decay_t<Func>>`.

### Функция `Free`

```cpp
template <typename T> void Free(T *ptr)
```

Освобождает память через `free()`, сбрасывая const-квалификатор при
необходимости.
